## Über KVisionCore

Die Idee hinter KVisionCore ist es, verschiedene digitale Projekte, Werkzeuge und Technologien an einem Ort zusammenzuführen.

Das Projekt soll Schritt für Schritt wachsen und sich mit der Zeit weiterentwickeln.

**Lyora** ist ein zukünftiges KI-Konzept innerhalb von KVisionCore.

Die Idee befindet sich noch in der Entwicklung und kann zukünftig neue Funktionen, Werkzeuge und Möglichkeiten erhalten.
